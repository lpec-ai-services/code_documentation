# 2D linear elastic thin plate with a hole in tension in python

This example exists in two flavours. In this file we focus on the one used with Python bindings of the MANTA frontend,
The second one relies used with the `C++` components, available [here](../../components_examples/elasticity/2D_elastic_thin_plate_with_hole_cpp.md#example-2d-elastic-thin-plate-with-hole-components)

## Description

[![figure](https://manta-project.gitlab.io/manta/_images/plate_with_hole1.svg)](https://manta-project.gitlab.io/manta/_images/plate_with_hole1.svg)

Fig. 8 Description of the 2D plate with a hole in compression

A thin plate with a hole is loaded in compression using a pressure
\(p^{\infty}\) on the right boundary, as illustrated on Figure
[Fig. 8](#fig-plate-with-hole-frontend). Due to symmetry, only a quarter
is meshed with the appropriate boundary conditions.

The behavior of the plate is supposed isotropic and linear elastic and
small perturbation hypothesis hold.

Table 14 Main parameters used in this test

|  |  |
| --- | --- |
| Radius of the hole | \(10^{-3}\, m\) |
| Length of the plate | \(0.11\, m\) |
| Height of the plate | \(0.1\, m\) |
| Imposed pressure \(p^{\infty}\) | \(10^{6}\, Pa\) |
| Young's modulus | \(210\,10^{9}\, Pa\) |
| Poisson's ratio | \(0.3\, Pa\) |

The main parameters of this test are reported on Table
[Table 14](#main-parameters).

Note that the elastic properties are required for the computation of the
strain and displacements but does not affect the stress distribution.

**Keywords:** structure, static, elastic, linear, 2D, qua4.

**References:**

- Analytical solution: Test SSLP 01/89 of [[SocieteFdMecaniciens90](../../../references/references.md#id35)].
- Numerical solution: Cast3M, 2022.

Warning

In this tutorial, a nonlinear resolution is used to overcome the
limitation of Release 0.1 of MANTA regarding linear bricks, in
particular the fact that those bricks are not able to compute the
stress.

Note

The following files are required to run the tutorial:

- [`mesh.dgibi`](https://manta-project.gitlab.io/manta/_downloads/db37572c1bd43faa1ce5c760398a1d56/mesh.dgibi):
  the `Cast3M` input file required to generated the mesh.
- [`Elasticity.mfront`](https://manta-project.gitlab.io/manta/_downloads/a829e7dcf02733a5c421888759f1e665/Elasticity.mfront): the MFront implementation of the mechanical behaviour
- [`plate_with_hole.py`](https://manta-project.gitlab.io/manta/_downloads/da65e6ad20bf4176ce2f3f82d787f555/plate_with_hole.py): the main script

## Implementation

The first line of the file `plate_with_hole.py` imports the MANTA module:

```python
import manta
```

The main parameters of the simulation, namely the Young's modulus, the
Poisson's ratio and the value of the imposed pressure
\(p^{\infty}\), are declared:

```python
properties = {'YoungModulus' : 210e9,
              'PoissonRatio' : 0.3}
pr = 1e6
```

### Definition of the physical system

The definition of the physical system imports the mesh generated by Cast3M:

```python
ps = manta.PhysicalSystem(mesh = {'file': 'plate_with_hole.med',
                                  'domains': ['plate'],
                                  'boundaries': ['left', 'bottom', 'right']},
                          geometricHypothesis = 'inPlane')
```

The geometric hypothesis is used to specify that the problem considered
is not axisymmetrical.

See Section [Physical system](../../../manta_frontend_user_guide/physical_system/physical_system.md#physical-system) for further details.

### Declaration of the material properties

The material properties are associated to the plate as follows:

```python
for n, v in properties.items():
    ps.addProperty('Constant', material = 'plate', name = n, value = v)
```

See Section [Properties](../../../manta_frontend_user_guide/properties.md#properties) for further details.

### Definition of the mechanical model, plate behavior and boundary conditions

The following lines declares the mechanical models and add bricks
associated with the behavior of the plate, the imposed displacement and
the imposed pressure:

```python
# tag::ksp_options_pymanta_manta_words[]
linear_solver_options = {'direct': {'factorizationBackend': 'mumps'},
                         'methodForConstraint': 'monolithic'}
# end::ksp_options_pymanta_manta_words[]

mechanics = manta.Model('ImplicitMechanics', ps,
                        nonlinearSolver = {'Newton': {'thresholdOnTheFirstResidualNorm': 1e-100,
                                                      'convergenceTolerances': {'relativeConvergenceTolerance': 1e-6},
                                                      'linearSolver': linear_solver_options}})

mechanics.add('SolidMaterial', material = 'plate',
              library = 'src/libBehaviour.so', behavior = 'Elasticity',
```

See Sections [Generalities on models](../../../manta_frontend_user_guide/models/generalities.md#generalities-on-models), [Solid mechanics models](../../../manta_frontend_user_guide/models/solid_mechanics/solid_mechanics.md#solid-mechanics-models),
and [Solid mechanics bricks](../../../manta_frontend_user_guide/bricks/solid_mechanics/solid_mechanics_bricks.md#solid-mechanics-bricks) for further details.

### Definition of the evolution of the imposed pressure

The evolution of the pressure is given by a constant function:

```python
mechanics.add('ImposedDisplacement', boundary = 'bottom', component = 'UY')
```

See Sections [Loadings](../../../manta_frontend_user_guide/loadings.md#loadings) for further details.

### Declaration of the auxiliary task for the projection of the stress on nodes

For the post-processing of the stress profiles, the stress must be
extrapolated on nodes. To do this, we will use the auxiliary task (i.e.
a model with no physical meaning) named
`L2ProjectionAuxiliaryTask` which minimizes the difference between
the values at nodes and at integration points using the \(L_{2}\)
norm.

This auxiliary task is declared as follows:

```python
              value = 'ImposedPressureValue')

ps.addLoadingEvolution('ImposedPressureValue', lambda t: pr)

# an auxiliary task: projection of the stress at nodes
```

See Section [The L2Projection auxiliary task](../../../manta_frontend_user_guide/auxiliary_tasks/l2_projection_auxiliary_task.md#l2-projection-auxiliary-taks) for further details.

### Declaration of the coupling scheme

The coupling scheme is, for this example, trivial: at each time step, we
call the mechanical model and extrapolate the stress values at nodes:

```python
                           result = 'NodalStress',
                           domain = 'plate',
                           numberOfRows = 4)

# coupling scheme
```

### Declaration of the post-processings

Two post-processings are defined:

- the first one exports the displacement field, the stress field at
  integration points and the stress field at nodes in a `VTK` file.
- the second one exports the profile the stress along the bottom file in
  a `txt` file.

```python
cs.add(mechanics)
cs.add(nodal_stress)
ps.setCouplingScheme(cs)

# post-processings

ps.addPostProcessing('VTKExport',
                     outputFileBaseName = 'results',
                     fields = [{'field': 'Displacement', 'fieldType': 'nodeField', 'material': 'plate'},
                               {'field': 'Stress', 'fieldType': 'ipField', 'material': 'plate'},
```

See Section [Post-processings](../../../manta_frontend_user_guide/post_processings/post_processings.md#post-processings) for a list of available post-processings.

### Running the simulation

The simple simulation is finally set and run:

```python
                     file = 'stress-bottom.res',
                     line = 'bottom',
```

See Section [Simulation](../../../manta_frontend_user_guide/simulation/simulation.md#simulation) for further details.

## Execution

The mesh can be generated by calling `Cast3M`, as follows:

```
$ castem24 mesh.dgibi
```

The elastic behaviour can compiled by invoking MFront:

```
$ mfront --obuild --interface=generic Elasticity.mfront
```

The simulation is run by executing Python:

```
$ python plate_with_hole.py
```

The simulation generates two files:

- `results.pvd`, which can be used to visualize in `paraview` the
  stress field (at integration points or its projection on nodes) or the
  displacement field. The displacement field can be used to deform the
  mesh.
- `stress-bottom.res`, which contains the profiles of the stress,
  extrapolated at nodes, along the `bottom` line for all time
  steps.

`manta-extractLineCurve` can be used to extract the profile at
time \(1\), as follows (see Section
[The manta-extract_line_curve_values utility](../../../manta_frontend_user_guide/miscellaneous/tools.md#manta-extra-line-curve-values) for details):

```
$ manta-extract_line_curve_values stress-bottom.res 1. -f txt -o stress-bottom-1.res
```

The resulting file, `stress-bottom-1.res` contains the curvilinear
abscissae, the coordinates of the nodes and the values of the stress in
columns. Such file can be directly used with `Matplotlib`, `gnuplot`
or your favorite tool to plot the stress profiles presented below.

## Results

The analytical solution for the stress distribution in an infinite plate
(see [[SocieteFdMecaniciens90](../../../references/references.md#id35)]) can be restricted to the bottom line of
the plate:

\[\begin{split}\begin{aligned}
\sigma_{rr} &= -\frac{p^{\infty}}{2}\,\left(2 - 5\,x^{2}+3\,x^{4}\right)\\
\sigma_{\theta\theta} &= -\frac{p^{\infty}}{2}\,\left(2\,x^{2}-3\,x^{4}\right) \\
\sigma_{r\theta} &= 0 \\
\end{aligned}\end{split}\]

[![figure](https://manta-project.gitlab.io/manta/_images/radial_stress.svg)](https://manta-project.gitlab.io/manta/_images/radial_stress.svg)

Fig. 9 Profile of the radial stress \(\sigma_{rr}\) along the bottom line

[Fig. 9](#fig-plate-with-hole-frontend-radial-stress) compares the
radial stress \(\sigma_{rr}\) given by analytical solution and the
numerical one computed by MANTA along the bottom line.

The agreement is satisfying if we take into account the fact that:

- the plate is not infinite in the MANTA simulation,
- the post-treated values are extrapolations at the nodes of the bottom
  line from the values at the integration points.

As expected due to the boundary conditions, the radial stress is null on
the left and equals \(-p^{\infty}\) on the right boundary.

[![figure](https://manta-project.gitlab.io/manta/_images/hoop_stress.svg)](https://manta-project.gitlab.io/manta/_images/hoop_stress.svg)

Fig. 10 Profile of the hoop stress \(\sigma_{\theta\theta}\) along the bottom line

[Fig. 10](#fig-plate-with-hole-frontend-hoop-stress) compares the
profiles of the hoop stress \(\sigma_{\theta\theta}\). The stress
concentration near the hole can be readily observed.

[![figure](https://manta-project.gitlab.io/manta/_images/shear_stress.svg)](https://manta-project.gitlab.io/manta/_images/shear_stress.svg)

Fig. 11 Profile of the shear stress \(\sigma_{r\theta}\) along the bottom line

[Fig. 11](#fig-plate-with-hole-frontend-shear-stress) confirms that
the stress \(\sigma_{r\theta}\) is negligible.
