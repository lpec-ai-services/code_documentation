# Main c++ User Concepts

This section aims at giving a general overview of
how to use MANTA c++ layer. It is splitted in two very similar
parts. First, a general overview of how a problem is solved in MANTA, along
with a brief description of its most important objects, are provided.
Then, the construction of a MANTA c++ file to solve this problem is described step by step.
