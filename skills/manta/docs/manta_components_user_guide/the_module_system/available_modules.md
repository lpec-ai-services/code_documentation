# Available modules

| Module name | Functionnality | Depends on |
| --- | --- | --- |
| xml_data_reader | Simple xml data reader | system |
| fem_tools | Provides generic functionalities to develop formulation using the finite element method | system  core |
| mbm | Provide the "mediating body method" for FSI with immersed structures | fvm_compressible_fluid_mechanics  modeling  xml_data_reader |
| io_gmsh | Provides a splitted gmsh reader  WARNING: if enabled, manta becomes contaminated by the GMSH licence (GPL-2.0-or-later) | system  core |
| hhom_implicit_structural_mechanics | Provides formulations to treat implicit structural mechanics problems with the HHO method | system  modeling  behavior  hhom_tools  xml_data_reader  testing_utilities |
| fvm_chimera | Provides chimera like functionalities to insert locally refined numerical model for some finite volume computations | fvm_tools  mbm |
| profiling | Provides profiling tools such as chronos. | system |
| core | Defines the MANTA's generic "pipeline".  Contains all the related data structures and "services" (mesh, fields, ...) | system  parameters  xml_data_reader |
| executable_utilities | Module providing useful features for executables | system |
| modeling | MANTA modeling module | core  behavior  fem_tools  xml_data_reader  io_vtk  io_med |
| hhom_tools | Provides generic tools to develop HHO formulations | system  modeling |
| fem_heat_transfer | Provides formulations to deal with heat transfer problems with the finite element method | system  fem_tools  evaluators |
| fem_thermomechanics | Provides functionalities for coupling between structural mechanics and thermal transfer | system  fem_heat_transfer  modeling  evaluators |
| fvm_compressible_fluid_mechanics | Provides formulations to treat compressible fluids with the finite volume method | fvm_tools  xml_data_reader  io_vtk |
| hhom_explicit | Provides experimental functionalities for HHO method with explicit time integrators | system  hhom_implicit_structural_mechanics  xml_data_reader |
| fvm_tools | Provide a set of tools to be used for the development of applicative module  dealing with the finite volume method. | core |
| io_med | Readers and writers for the MED format | core |
| parameters | Handle MANTA's `parameters` which map a `json` data structure.  Provides a `json` file reader. | system |
| system | Defines all the base stuff.  Ex: numeric types, error management, containers, MPI tools, ... |  |
| fem_phasefield_damage | Provides formulations to treat problems with phasefield damage | system  modeling  xml_data_reader |
| behavior | Provide functionalities to handle behavior through mgis | system  core |
| fracture_mechanics | Provides numerical methods for linear elastic fracture mechanics (G-Theta) | system  modeling |
| io_vtk | Provides writer in VTK format. | system  core |
| fem_micromorphic_damage | Provides formulations to treat problems with micromorphic damage | system  modeling  behavior |
| incompressible_navier_stokes_fe | Formulations based on the finite element method to simulate  the incompressible Navier Stokes equations for Newtonian fluids. | system  modeling  fem_tools |
| fvm_misc | Provides formulation for advection, burgers equation, ... (mainly for  research on numerical methods) with the finite volume method. | fvm_tools |
| hhom_vtk_writer | Provides specific writer in vtk format to display HHO discontinuous fields | io_vtk  modeling  core  system |
| evaluators | Abstract evaluators | core |
| testing_utilities | Module just used for internal tests | system  parameters |
| medsplitter | Executable allowing to split a input mesh file in MED format into N files using a partitioning algorithm | io_med |
| info | Gives info about the frontend | manta |
| extract_line_curve_values | The manta-extract_line_curve_values utility can be used to extract data from a file generated by the LineCurve post-processing of the frontend | core |
| manta | Executable to use the manta's frontend | manta |
| manta | High level API | evaluators  parameters  modeling  fvm_compressible_fluid_mechanics  io_vtk  io_med  fem_heat_transfer  fem_micromorphic_damage  xml_data_reader |
| gmsh_splitted_reader | Add the gmsh splitted reader to the fontend | io_gmsh |
| explosion | Module holding models for solid explosives (TNT,...), especially built around JWL equation of state. | system  fvm_compressible_fluid_mechanics  io_vtk |
| edf | Provides all private features needed for EDF industrial applications : LOCA, IMPACT, HELB | system  fvm_compressible_fluid_mechanics  io_vtk |
| incompressible_navier_stokes_fe | Formulations based on the finite element method to simulate  the incompressible Navier Stokes equations for Newtonian fluids. | system  modeling  io_vtk  executable_utilities |
