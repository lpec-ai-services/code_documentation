# Command line tools

This section describes various command line utilities.

## The `manta-extract_line_curve_values` utility

The `manta-extract_line_curve_values` utility can be used to extract data
from a file generated by the LineCurve post-processing at various time
as follows:

```sh
$ manta-extract_line_curve_values temperature-profile.txt 1
```

The first argument of the `manta-extract_line_curve_values` utility is the
name of the file treated. The other arguments are the list of times for
which data are extracted.

The output of `manta-extract_line_curve_values` also transposes the values
extracted, which eases plotting the data.

## The `manta-info` utility

The `manta-info` utility allows to retrieve some documentation
about various aspects of the code.

The documentation is organized in a tree.

The `manta-info` utility takes one or several paths to the section
of interest as argument.

If no path is given, the list of the main sections of the documentation
is displayed:

```sh
$ manta-info
The following subsections are available:

- Model bricks
- Coupling schemes
- Properties
- Loadings
- Factories
- Models
- Post-Processings
```

Paths are list of sections separated by the character `:`. For
example, the following call retrieve the documentation about the
`Model bricks` subsection of the `Models` section.

```sh
$ manta-info Models:"Model bricks"
The following model bricks are available:

- ImplicitMicromorphicDamageSolidMaterial: a brick describing a solid material
- ImposedDisplacement: this brick can be used to impose the value of the displacement field
- ImplicitMechanicsSolidMaterial: a brick describing a solid material
- ImposedTemperature: this brick can be used to impose the value of the temperature field
- HeatSource: a brick describing a solid material
- ImplicitHeatTransferSolidMaterial: a brick describing a solid material
- DirichletBoundaryCondition: a brick use to impose Dirichlet boundary conditions
```

Some sections of the documentation can be affected by parameters passed
on the command line. Currently, only the boolean parameter
`showParameters` is supported for sections associated with
factories or items that can be created by factories. For example:

```sh
$ manta-info --parameter=showParameters:true Models:"Model bricks"
The following model bricks are available:

- ImplicitMicromorphicDamageSolidMaterial: a brick describing a solid material
  - macroscopicGradientsEvolutions: map associated macroscopic gradients components and loadings evolutions
  - defaultTangentOperator: default tangent operator. Valid values are: 'Elastic', 'Secant', 'Tangent' and 'ConsistentTangent'. If this option is not used, the 'ConsistentTangent' value is used by default.
  - hypothesis: structural hypothesis (string). Valid values are: `PlaneStrain`,  `PlaneStress`,  `Tridimensional`, etc.
  - behavior: name of MFront behavior (string)
  - materials: materials names (regular expressions) (equivalent to `domains`)
  - library: path to the MFront library (string)
  - domains: domains names (regular expressions) (equivalent to `materials`)
  - integrationScheme: the integration scheme. 'default' is currently the only valid value
  - material: material name (regular expression) (equivalent to `domain`)
  - domain: domain name (regular expression) (equivalent to `material`)
  - quadratureOrder: order of quadrature (optional)
 ...
```

## The `manta` executable

The `manta` executable can be used to launch simulations from a
JSON input file. This executable is mostly used to showcase JSON
input file and testing purposes.
