# Point-wise models

Contents

- [The `MFrontPointWiseModel` model](mfront_point_wise_model.md)

Point-wise models describe local evolutions of some state variables of a
material. Here, local means that each integration points can be treated
independently and that no global resolution is required.

Point-wise models can describe swelling under irradiations, phase
changes, etc.
