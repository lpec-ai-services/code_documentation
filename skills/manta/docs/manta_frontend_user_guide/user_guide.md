# User guide of the MANTA and PyManta frontends

This document focuses on the MANTA and PyManta frontends which are
designed for engineering studies, code coupling or building
domain-specific applications. Those frontends are:

- focused on the description of coupled physical phenomena to be
  treated (heat transfer, mechanics, diffusion, etc...),
- stable in time,
- simple to use (requiring only minimal programming skills),
- designed to work "out of the box" in most cases (parameters and
  algorithms, although modifiable, are hidden by default),
- verified and -when possible- qualified,
- documented,
- extensible by the MANTA components by a plugin system. The MANTA
  components are described in the [User guide of the MANTA components](../manta_components_user_guide/manta_components_user_guide.md#manta-components-user-guide).
