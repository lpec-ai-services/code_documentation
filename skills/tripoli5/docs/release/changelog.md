# Changelog

## 0.3.0

- Compilation with c++20 standard
  This requires ROOT to be compiled with the c++20 standard
- API changes for the declaration of boundary conditions for the `AGORA` geometry.
- Default behavior changes:

  - SVT model is turn on for H1 up to the upper energy limit of the simulation
  - ACE Probability tables are turned on by default
  - Forbid declaring duplicate isotopes in a Mixture
- A preliminary implementation of the new score system is available (see new_scores.ipynb)

  - As a consequence, the previous system is deprecated and will be removed in a future version
- Updating compositions of a Mixture through the Icoco system
- Logging can now be outputed directly into a file
  * an exemple is provided in the simulation.ipynb notebook
- Function to load a filler generated by CASTOR
- Allow a user-defined threshold for the thermal scattering law
- Bug fix on Temperature stochastic interpolation

  - preserve correlations when having multiple flights between collisions.
  - incorrect loading when used with delta tracking
  - fix majorant calculation
- Allow modfying the basename of used to reconstruct file names in the catalog.
  This allows using the same file for multiple isotopes (useful for TSL)

## 0.2.0

This is the second TRIPOLI-5 release (15 December 2025)!

### Main features

- Compilation with c++17 standard
  This requires ROOT to be compiled with the c++17 standard
- Reflective boundary conditions for the `AGORA` geometry
- Stochastic interpolation for temperature dependence of cross sections
- Implicit capture and nuclide-wise branchless collision sampling
- Population control. Splitting and russian roulette with constant parameters for all particles
- Possibility of using custom temperature and path files in the catalog
- Added validation configurations [Validation](../index.md#validation)
- Scores

  - Flux with custom energy mesh on all volumes
  - Reaction rate over a MEDMesh filtered by composition
  - Added track-length estimators for GeneralSpectrum tally
- Various performance improvement

  - One consequence is that materials are reordered in the geoemtry.
    This may lead to changing plot colors.

## 0.1.0

This is the initial TRIPOLI-5 release (12 December 2024)!

### Main features

- Virtually complete support for neutron physics. This includes:

  - Free gas model
  - [Thermal scattering laws](../theory/collision_physics/tsl.md#thermal-scattering-laws)
  - Probability tables for the unresolved resonance range (URR; this feature requires
    further testing)
  - Doppler broadening of the elastic scattering law

    - [SVT](../theory/collision_physics/svt.md#the-svt-algorithm) and DBRC methods
  - On-the-fly Doppler broadening with the SIGMA1 method

    - CPU version
    - CUDA-based GPU version
- Geometry

  - Multiple models

    - `AGORA` (native TRIPOLI-5 model)
    - [ROOT](https://root.cern.ch/) (fully compatible with TRIPOLI-4)
  - Preliminary version of a native, `matplotlib`-based plotting tool
    ([`GeoPlotterPyplot`](../api/geoplotter-api.md#tripoli5.geoplotter.GeoPlotterPyplot))
- Simulation types

  - Criticality
  - Fixed-source
- Source types

  - Factorized space/energy/angle source
  - Pointwise isotropic source
  - Several space/energy/angle distributions are possible
- Scores

  - Effective multiplication factor
  - Flux
  - Macroscopic reaction rates
  - Fission-weighted Q-value (also knowns as kappa or κ; can be used as a rough ersatz
    for energy deposition)
  - Flux and kappa scores can also be scored on a MEDCoupling mesh
- [Examples](../api/geoplotter-api.md#id10) and [documentation](../index.md#documentation-top)
