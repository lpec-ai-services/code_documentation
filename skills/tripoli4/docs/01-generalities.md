## 1.1 GENERAL DESCRIPTION OF THE CODE

The TRIPOLI-4® code is a three-dimensional, continuous energy computer code for particle transport based on the Monte Carlo
method. The code currently simulates the transport of neutrons, photons, electrons, and positrons [18, 44].
TRIPOLI-4® is designed for two major classes of problems, those relating to radiation shielding and those relating to reactor
physics. Radiation shielding problems deal with particle propagation over long distances with many orders of magnitude of flux
attenuation. These arise with sources in non-multiplying media, in steady-state and time-dependent conditions. Problems related
to reactor physics refer to the behavior of particles in multiplying media. The system can be either critical or sub-critical, with or
without fixed sources, under steady-state conditions.
The code builds on previous versions of TRIPOLI: TRIPOLI-1, TRIPOLI-2, and TRIPOLI-3 [88], [89], [1], [100], the development
of which began in the late sixties and early seventies. It differs from earlier versions in that it has been completely rewritten in more
recent programming languages (C and C++), with fuller descriptions of geometrical elements (surface-based and/or combinatorial
geometries) and more precise representations of basic nuclear data (pointwise representation of cross-sections, although the code
also allows multigroup homogenized cross-sections) [18].
For additional information, see also the website:
https://www.cea.fr/energies/tripoli-4

## 1.2 PURPOSE OF THIS DOCUMENT

This manual provides a full description of the code and describes the syntax of the TRIPOLI-4® code data.

## 1.3 EXECUTION

The code execution call (assuming that the executable is named tripoli4) is as follows (the options are to be entered on the same
line as the tripoli4) command:

<!-- page 22 -->
tripoli4
-d <data_file>
-s <format>
-c <path_file>
-o <results_file>
-l <language>
-T notest
-x
-a
-u
-j <Njoy_code_path>
-k
-P <command>
-H
The options in bold are required; those in italics are optional. Descriptions of these options are as follows:
• The option -d is used to specify the data file <data_file>. The syntax of the data file will be explicitly defined in the
following chapters.
• The option -s is used to specify the format for the cross-sections. <format> equals:
– NJOY, for a calculation with pointwise cross-sections from NJOY 99;
– TABPROB, for a calculation with pointwise cross-sections from NJOY 99 for the resolved range, and probability tables
for the unresolved resonance range from CALENDF.
– ENDL, for a calculation with pointwise cross-sections from the EPDL libraries for high energy photons: up to 1 GeV
(this is the option that must be chosen in order to simulate an electromagnetic shower without loading neutron data, for
example);
– GENDF, for a calculation with multigroup cross-sections generated by the GROUPR module of the NJOY code.
– TABPROB_GENDF, for a calculation with multigroup cross-sections in GENDF format, and probability tables in
CALENDF format.
It should be noted that for a calculation with homogenized multigroup cross-sections (in APOTRIM format from the APOLLO2
code) [95] the choice of this option has no bearing on the calculation.
Restrictions when using the GENDF and TABPROB_GENDF formats:
neutron-only problem, calculation in a nonmultiplying
medium, natural simulation (without biasing), no neutron thermalization, no point-based estimators, no energy
deposition calculations, no perturbation.
• The -c option is used to specify the file <path_file> containing the access paths for the nuclear data required by the code.
• The -o option is used to specify the file <results_file> where the code output is to be stored.
• The -l option is used to indicate the language used when entering the keywords. The possible values for <language> are
“english,” “french,” and “old”. The last option is a mixture of English and French words. It referred on the column
Default (old) of Annex C. It used to be the only choice up to version 3 of TRIPOLI-4®. The line -l <language> is optional,
and the default language is “old.”
This option can be replaced or overridden by the keyword LANG < language > in the very beginning of the data file, <
language > being FRENCH or ENGLISH.
Important Note : the keywords for this manual correspond to the option english. For other choices, see Annex C. Warning:
some keywords in the english option have been modified with respect to version 4.3 of the code for reasons of clarity.

<!-- page 23 -->
• The -T notest option disables the geometrical checks. This option can be useful when the checks are lengthy and the geometry
has already been tested during an earlier calculation.
• The -x option can be used to disable the sorting of the scores by volume number during edition. By default, the scores edition
is sorted by volume number.
• The -a option should be used if all of the results are required. In this case, even zero results will be displayed in the output.
This option is useful for the post-processing of output files generated by TRIPOLI-4®. Starting from version 12 of TRIPOLI-
4®, this option is set by default. The inverse option is -z, which prints only non-zero values.
• The -u option should be used to display results with physical units (see section 1.4)
• The -j option is used to couple the TRIPOLI-4® and NJOY 99 codes (generation of cross-section files at given temperatures
, see the section 10.4). <Njoy_code_path> is the path for the NJOY executable. It could, for example, be ‘which
njoy_executable_name‘. This option should exclusively be run in mono-processor mode. If any run in parallel should accidentally
occur, the created cross-section files must be cleaned and the run should be executed again in mono-processor
mode.
• The -k option enables compatibility with nuclear data libraries (namely .aniso, .xdr and .dictio files) processed by versions
of the TRIPOLI-4® code earlier than 7 : the reading of cross-sections for new interactions implemented in the version 7 (see
Notes on Table 13.1 of chapter 13) is disabled. Warning: starting with version 11, this option is deprecated and may be
removed in a future release.
• The -R option disables the checks of which ROOT version is used.
• The -P <command> option enables the precompilation of the data file. <command> can simply be the name of the precompiler
if this one is to be called without arguments or the complete command line with quotes.
WARNING ! If the -P option is to be used with cpp, it is reminded that, by default, the cpp precompilation will add ’#’
characters within the data file that will cause TRIPOLI-4® to crash. To avoid this behaviour, the -P option of cpp should be
added within <command>.
Examples of use of the -P <command> option of TRIPOLI-4® are given below:
-P m4
-P’m4 -Dbatch=10’
-P’cpp -P -Dbatch=10’
• The help option -H is used to obtain a list of the execution options for the TRIPOLI-4® code.

## 1.4 DISPLAYING PHYSICAL UNITS

Option -u allows the user to display physical units. The displayed units are relevant for steady state calculations and are described
in chapter 13. These units may not be correct for transient calculations.
This option must not be used if the user has requested a change of units in the input deck (see section 4.2).
In this case, the displaying of units will be disabled with a warning.
Displaying units will not turn on any special check on the sums. In cases where the user has requested a sum, the units of the first
term of the sum will be displayed without verifying that the other terms are consistent.

## 1.5 VERSION NUMBER

The code now outputs the number of the version into the results file.
This information can be obtained by entering tripoli4 -V (or tripoli4 --version), where tripoli4 is the name of the
executable (with the path if necessary).

## 1.6 VERIFICATION AND VALIDATION TOOL VALJEAN

Most of the results of TRIPOLI-4® calculations are provided in ASCII format. VALJEAN is an open-source Python library that
can be used to parse the TRIPOLI-4® output into data structures suitable for post-processing and manipulation. VALJEAN provides
tools to perform statistical tests on datasets and produce extensive and customizable reports.
The VALJEAN documentation and installation instructions can be found at https://valjean.readthedocs.io/.
The minimum VALJEAN version required for parsing outputs of TRIPOLI-4® version 12 is v0.10.
