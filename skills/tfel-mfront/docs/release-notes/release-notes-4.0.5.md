The page describes the new functionalities of Version 4.0.5 of the
`TFEL` project.

This version was released on May 12, 2025 along with:

- [Version 3.0.15](release-notes-3.0.15.md),
- [Version 3.1.15](release-notes-3.1.15.md),
- [Version 3.2.12](release-notes-3.2.12.md),
- [Version 3.3.7](release-notes-3.3.7.md),
- [Version 3.4.8](release-notes-3.4.8.md),

and inherits from all fixes from those releases.
