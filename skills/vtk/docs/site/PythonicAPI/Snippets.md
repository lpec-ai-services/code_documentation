# Snippets

### Description

Snippets are chunks of code that can be cut (*snipped*) and pasted into examples. We want each example to be stand-alone, so we do not keep the snippet code in a library.

### Available snippets

| Snippet | Description |
| --- | --- |
| [Callbacks](Snippets/Callbacks.md) | Implementing callbacks. |
| [CameraOrientationWidget Placement](Snippets/COWPlacement.md) | Define the parameters that label, color and position a [vtkCameraOrientationWidget](https://www.vtk.org/doc/nightly/html/classvtkCameraOrientationWidget.html). |
| [CameraPosition](Snippets/CameraPosition.md) | Get the camera position and focal point. |
| [CheckVTKVersion](Snippets/CheckVTKVersion.md) | Check the VTK version returning `True` if the requested VTK version is >= the current version. |
| [DrawViewportBorder](Snippets/DrawViewportBorder.md) | Draw a border around a renderer's viewport. |
| [GetProgramParameters](Snippets/GetProgramParameters.md) | Get the program parameters. |
| [GetTextPositions](Snippets/GetTextPositions.md) | Get viewport positioning information for a list of names. |
| [Make2DSliderWidget](Snippets/Make2DSliderWidget.md) | Implement 2D slider widgets. |
| [Permute](Snippets/Permute.md) | Permute image and other geometric data to maintain proper orientation regardless of the acquisition order. |
| [PointToGlyph](Snippets/PointToGlyph.md) | Represent points as glyphs. |
| [ReadPolyData](Snippets/ReadPolyData.md) | Uses the appropriate [vtkPolyData](https://www.vtk.org/doc/nightly/html/classvtkPolyData.html) reader to read any vtkPolyData file. |
| [ScreenShotCallback](Snippets/ScreenshotCallback.md) | Take a screenshot from the render window by pressing a key on the keyboard. |
| [Slider3D](Snippets/Slider3D.md) | Implement a 3D slider widget. |
| [VTKDataClasses](Snippets/VTKDataClasses.md) | The VTK immutable data classes for constants. |
| [WriteImage](Snippets/WriteImage.md) | Take a screenshot from the render window and write it to a file. The file extension selects the writer to use. |
