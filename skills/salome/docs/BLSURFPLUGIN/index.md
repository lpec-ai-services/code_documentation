# Introduction to MG-CADSurf plug-in

**MG-CADSurf** plug-in adds MG-CADSurf (former BLSURF) meshing algorithm to the SALOME Mesh module.

**MG-CADSurf** meshing algorithm is destined for:

- generation of 2D meshes basing on the 2D geometric entities (faces).

Note
:   MG-CADSurf plug-in uses DISTENE MG-CADSurf commercial meshing software and requires a license at the run time (to work within the Mesh module). To obtain a license, visit <http://www.meshgems.com/meshgems-products.html>

To manage parameters of the MG-CADSurf mesher, use [MG-CADSurf Parameters hypothesis](blsurf_hypo_page.md).

Also, all MG-CADSurf functionalities are accessible via the [MG-CADSurf Python interface](blsurfplugin_python_interface_page.md).
