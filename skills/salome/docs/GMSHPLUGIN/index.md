# Introduction to GMSHPLUGIN

**GMSHPLUGIN** plugin provides an integration of certain functionalities of the well known [**Gmsh three-dimensional finite element mesh generator**](https://www.gmsh.info). It is possible to mesh 2D and 3D geometric entities. The plugin was especially developed to integrate the Gmsh compound functionality. The plugin provides support of sub-meshes.

To manage parameters of the GMSHPLUGIN use [Gmsh 2D and 3D hypotheses](gmsh_2d_3d_hypo_page.md).

Also all GMSHPLUGIN functionalities are accessible via [GMSHPLUGIN Python interface](gmshplugin_python_interface_page.md).
