# Auxiliary Python API of Geometry module

Python API of Geometry module includes some additional packages:

- Sketcher module [gsketcher.py](geompy_doc/group__sketcher.md) to create 2D / 3D sketches
- Simplified sketcher module [sketcher.py](geompy_doc/group__simplesketcher.md) (deprecated)
