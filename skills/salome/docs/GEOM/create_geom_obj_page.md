# Creating geometrical objects

Salome Geometry module provides the toolset allowing to create a vast range of geometrical objects, from points to complex extrusions:

- create [Basic objects](create_basic_geom_obj_page.md) - points, lines, circles...
- create [Primitives](create_primitives_page.md) - cubes, spheres, cones...
- create [Complex objects](create_complex_obj_page.md) by extrusion, rotation, interpolation of other objects.
- create and edit [Groups of objects](work_with_groups_page.md) of lower dimension, which belong to the objects of higher dimension.
- [Build by blocks](build_by_blocks_page.md) faces from edges and solids from faces.
- [Explode](create_explode_page.md) objects of higher dimension into sub-objects of lower dimension.
- create [Topological objects](create_topological_obj_page.md) - edges, wires, shells...

Note
:   It is possible to use the variables defined in the SALOME **NoteBook** to specify the numerical parameters for creation of any object.
