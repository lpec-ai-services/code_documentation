# Transforming geometrical objects

The objects created in Salome can be processed with Transformation operations, which can be classified into:

- [Boolean operations](using_boolean_operations_page.md), which allow combining objects with boolean logical operators.
- [Transformation operations](transformation_operations_page.md), which modify shape or location of the selected object.
- [Features](features_page.md), which allow adding or removing matter from an object.
- Operations with [Blocks](blocks_operations_page.md).
- [Partition](partition_page.md) operation, which creates a compound by intersection of several shapes with a tool object or a plane.
- [Archimede](archimede_page.md) operation, which creates a plane corresponding to the modelled waterline of the object plunged into water.
- [Get shapes on shape](shapesonshape_page.md) operation, a special case of **Explode** operation.
- [Get shared shapes](shared_shapes_page.md) operation, a special case of **Explode** operation.
- [Transfer Data](transfer_data_page.md) operation, which copies non-topological data from one shape to another.
- [Extract and Rebuild](extract_and_rebuild_page.md) operation, which extracts sub-shapes from the main shape.
- [Restore presentation parameters](restore_presentation_parameters_page.md). This cross-operation functionality allows the resulting shape to inherit colors and sub-shapes from its parent shapes.
