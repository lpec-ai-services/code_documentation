# Transformation Operations

Geometry module provides the following transformation operations, which allow to:

- [Translate](translation_operation_page.md) an object by a certain vector.
- [Rotate](rotation_operation_page.md) an object around a certain axis by a certain angle.
- [Move](modify_location_operation_page.md) an object to a new location.
- [Mirror](mirror_operation_page.md) an object through a point an axis or a plane of symmetry.
- [Scale](scale_operation_page.md) an object by one or several scale factors.
- Create an [Offset](offset_operation_page.md) of an object.
- Create a [Projection](projection_operation_page.md) of an object on a face.
- Create an [Extension](extension_operation_page.md) of an edge or a face.
- Create a [Projection on cylinder](projection_on_cylinder_operation_page.md).
- Create a simultaneous [Translation in several directions](multi_translation_operation_page.md).
- Create a simultaneous [Multi Rotation](multi_rotation_operation_page.md) "Rotation in several directions".
