# Blocks Operations

The solids built by blocks [Building by blocks](build_by_blocks_page.md) can be processed with blocks transformation operations:

- [Multi-transformation](multi_transformation_operation_page.md) - produces several translations of a block in one or two directions.
- [Explode on blocks](explode_on_blocks_operation_page.md) - returns blocks of the given compound.
- [Propagate](propagate_operation_page.md) - builds all possible propagation groups from the given shape.
