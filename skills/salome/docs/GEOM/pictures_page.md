# Designing shapes from pictures

Some tools in [GEOM](../GEOM/geompy_doc/namespaceGEOM.md) allow you to create shapes, basing the design on imported pictures (engineering drawings, nautical charts ...) :

- [Import a picture in the OCC viewer](import_picture_page.md), such as engineering drawings or nautical charts as a support for shape design.
- [Shape recognition from a picture](shape_recognition_page.md) previously imported in the OCC viewer .
