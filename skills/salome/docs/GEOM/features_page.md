# Features

Geometry module provides the following Features, which allow to:

- Produce a [1D Fillet](fillet1d_operation_page.md) on the corners of a Wire with Planar Edges.
- Produce a [2D Fillet](fillet2d_operation_page.md) on the corners of a Planar Face.
- Produce a [3D Fillet](fillet_operation_page.md) on the selected edges of an object.
- Produce a [Chamfer](chamfer_operation_page.md) on the selected edges of an object.
- Remove matter from an object by producing an [Extruded Cut](extruded_cut_operation_page.md).
- Add matter to an object by producing an [Extruded Boss](extruded_boss_operation_page.md).
