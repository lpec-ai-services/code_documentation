# Introduction to Geometry

![geomscreen.png](https://docs.salome-platform.org/latest/gui/GEOM/geomscreen.png)

**Geometry** module of SALOME is destined for:

- [import and export of geometrical models](import_export_geom_obj_page.md) in IGES, BREP, STEP, STL, XAO and VTK formats;
- [construction of geometrical objects](create_geom_obj_page.md) using a wide range of functions;
- [viewing geometrical objects](view_geom_obj_page.md) in the OCC viewer;
- [transformation of geometrical objects](transform_geom_obj_page.md) using various algorithms;
- [optimization of geometrical objects](repairing_operations_page.md);
- viewing information about geometrical objects using [measurement tools](using_measurement_tools_page.md);
- [designing shapes from pictures](pictures_page.md);
- [defining fields](geom_field_page.md).

It is possible to easily set parameters via the variables predefined in [SALOME notebook](using_notebook_geom_page.md).

Geometry module preferences are described in the [Geometry preferences](geometry_preferences_page.md) section of SALOME Geometry Help.

Almost all geometry module functionalities are accessible via [Geometry module Python Interface](python_interface.md)

You can find the answer to some Frequently Asked Questions in this page:

- [Frequently Asked Questions](faq.md)
