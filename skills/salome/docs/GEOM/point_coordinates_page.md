# Point Coordinates

This operation returns XYZ coordinates of the selected point.

![measures1.png](https://docs.salome-platform.org/latest/gui/GEOM/measures1.png)

**TUI Command:** *geompy.PointCoordinates(Point),* where *Point* is a point whose coordinates are inquired.

See also a [TUI example](tui_point_coordinates_page.md).
