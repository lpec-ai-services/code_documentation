# Creating Complex Objects

**New entity -> Generation** sub-menu allows creating new geometric objects by modification and multiplication of the existing objects:

- [Extrude](create_extrusion_page.md) a 2D object by vector, creating a 3D object.
- [Revolve](create_revolution_page.md) an object around an axis, creating a body of revolution.
- [Create a surface](create_filling_page.md) from a set of edges.
- [Extrude an object along a path](create_extrusion_alongpath_page.md), creating a more complex trajectory object.
- [Restore Path](create_pipe_path_page.md) of a pipe-like shape.
- [Add thickness](create_thickness_page.md) to objects.
- [Generate Groups](create_groups_page.md) for certain generation operations.

**New entity -> Advanced**  sub-menu allows creating new geometric objects using advanced algorithms:

- [Smoothing surface](create_smoothingsurface_page.md) from a cloud of points.
