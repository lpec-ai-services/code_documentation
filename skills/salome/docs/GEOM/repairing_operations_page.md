# Repairing geometrical objects

Repairing operations improve the shapes, processing them with complex algorithms:

- [Shape processing](shape_processing_operation_page.md) - processes one or more shapes using various operators.
- [Suppress faces](suppress_faces_operation_page.md) - removes chosen faces of a shape.
- [Close contour](close_contour_operation_page.md) - closes an open contour asnd miodifies the underlying face.
- [Suppress internal wires](suppress_internal_wires_operation_page.md) - removes internal wires from shapes.
- [Suppress holes](suppress_holes_operation_page.md) - removes holes with free boundaries on a selected face.
- [Sewing](sewing_operation_page.md) - sews faces or shells.
- [Glue faces](glue_faces_operation_page.md) - unites faces coincident within the given tolerance.
- [Glue edges](glue_edges_operation_page.md) - unites edges coincident within the given tolerance.
- [Limit Tolerance](limit_tolerance_operation_page.md) - tries to set new tolerance value for the given shape.
- [Add point on edge](add_point_on_edge_operation_page.md) - splits an edge in two.
- [Change orientation](change_orientation_operation_page.md) - reverses the normals of the selected faces.
- [Remove internal faces](remove_webs_operation_page.md) - rebuilds the topology of solids by removing the faces are shared by several solids.
- [Remove extra edges](remove_extra_edges_operation_page.md) - removes seam and degenerated edges from the given shape.
- [Fuse Collinear Edges within a Wire](fuse_edges_operation_page.md) - removes selected vertices from a given wire in case if adjacent edges are C1 continuous.
- [Union faces](union_faces_operation_page.md) - unites on a given shape all faces sharing the same surface.
