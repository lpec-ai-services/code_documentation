# Connector plug-in

Connector plug-in is used to export Results, Groups, Fields created in active part into GEOM module:

1. select in the Main Menu *Feature - > Export to GEOM* item or
2. click ![geom_export.icon](https://docs.salome-platform.org/latest/gui/SHAPER/_images/geom_export.png) **Export to GEOM** button in Shaper toolbar:

**TUI Command**:

model.exportGEOM(*part*)
:   Parameters:
    :   **part** – The current part object

The result can be checked in GEOM module.
