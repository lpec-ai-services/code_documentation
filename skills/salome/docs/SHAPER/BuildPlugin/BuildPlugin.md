# Build plug-in

Build plug-in includes features for creation of various topological entities. It provides the following features:

- [Compound](compoundFeature.md)
- [CompSolid](compsolidFeature.md)
- [Edge](edgeFeature.md)
- [Face](faceFeature.md)
- [Filling](fillingFeature.md)
- [Interpolation](interpolationFeature.md)
- [Polyline](polylineFeature.md)
- [Shell](shellFeature.md)
- [Solid](solidFeature.md)
- [Sub-shapes](subShapesFeature.md)
- [Vertex](vertexFeature.md)
- [Wire](wireFeature.md)
