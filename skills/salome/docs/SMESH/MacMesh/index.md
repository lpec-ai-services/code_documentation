MacMesh for Salome

# The multi-purpose Salome plug-in for regular 2D meshing

- Consider reading [User manual](https://docs.salome-platform.org/latest/gui/SMESH/MacMesh/MacMesh.v.10avr.pdf)  to learn how to use the plug-in
- Type *import PressureValve* in the Python console of
  Salome to run a sample script
- [Download the sample script](https://docs.salome-platform.org/bin/salome/PressureValve.py)
- Python files of the plugin are located in   
  ${SMESH_ROOT_DIR}/share/salome/plugins/smesh/MacMesh  directory
