# Double nodes

This mesh quality control highlights the nodes which are coincident with other nodes (within a given tolerance). Distance at which two nodes are considered coincident is defined by [Quality Controls/Double nodes tolerance](mesh_preferences.md#dbl-nodes-tol-pref) preference.

![figure](https://docs.salome-platform.org/latest/gui/SMESH/_images/double_nodes.png)

**Some nodes are coincident after copying all elements with translation.**

**See also**: A sample TUI Script of a [Double nodes](tui_filters.md#tui-double-nodes-control) filter.
