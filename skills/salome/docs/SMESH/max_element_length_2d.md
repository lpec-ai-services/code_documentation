# Element Diameter 2D

This quality control criterion consists in calculation of the maximal length of edges and diagonals of 2D mesh elements (triangles and quadrangles). For polygons the value is always zero.

*To apply the Element Diameter 2D quality criterion to your mesh:*

1. Display your mesh in the viewer.
2. Choose **Controls > Face Controls > Element Diameter 2D** or click *“Element Diameter 2D”* button ![img](https://docs.salome-platform.org/latest/gui/SMESH/_images/image42.png) in the toolbar.

   Your mesh will be displayed in the viewer with its elements colored according to the applied mesh quality control criterion:

   > ![figure](https://docs.salome-platform.org/latest/gui/SMESH/_images/max_element_length_2d.png)
