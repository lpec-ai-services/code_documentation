# Display Mode

By default your objects are represented as defined in [Mesh Preferences](mesh_preferences.md#mesh-tab-preferences).
However, right-clicking on the mesh in the **Object Browser**, and selecting **Display Mode**, you can display your mesh as:

![figure](https://docs.salome-platform.org/latest/gui/SMESH/_images/image53.gif)

**Wireframe**

![figure](https://docs.salome-platform.org/latest/gui/SMESH/_images/image37.jpg)

**Shading**

![figure](https://docs.salome-platform.org/latest/gui/SMESH/_images/image56.gif)

**Nodes**

**Wireframe** can combine with **Nodes** and **Shading**.

**Shading** and **Wireframe** modes can combine with **Shrink**, however **Nodes** can’t.
