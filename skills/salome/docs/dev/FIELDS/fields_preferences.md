# Preferences

![figure](https://docs.salome-platform.org/latest/dev/FIELDS/_images/image_fields_preferences.png)

Preferences dialog allows choosing icons theme for use in Fields module.
One of the following themes can be chosen:

- **Modern**: modern icons

![figure](https://docs.salome-platform.org/latest/dev/FIELDS/_images/image_icons_modern.png)

- **Classic**: classic icons

![figure](https://docs.salome-platform.org/latest/dev/FIELDS/_images/image_icons_standard.png)
