# Mesh presentation

![figure](https://docs.salome-platform.org/latest/dev/FIELDS/_images/image_mesh_prs.png)

The main purpose of this presentation is to display the mesh structure without any physical data.

This presentation is automatically created when importing a [Data Source](fields_data_source.md#fields-data-source-page).
Additionally, **Mesh** presentation can be created by

- Selecting a Mesh item in the **Object Browser**, and
- Choosing **Presentations > Mesh** menu or clicking ![img_msh](https://docs.salome-platform.org/latest/dev/FIELDS/_images/image_mesh.png) button in the *Presentations* toolbar.
