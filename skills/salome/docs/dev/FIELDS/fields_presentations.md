# Presentations

![figure](https://docs.salome-platform.org/latest/dev/FIELDS/_images/image_representations.png)

Fields module allows creating several types of presentations. All presentation types can be split in two main groups:

- [Mesh presentation](fields_mesh_presentation.md#fields-mesh-presentation-page): can be created on a mesh
- [Fields Presentations](fields_fields_presentation.md#fields-fields-presentation-page): can be created on a field
