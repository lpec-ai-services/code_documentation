# Manage groups on the model

## Add group

A group is characterized by:

- its name,
- its type:
  :   - HexaCell (default)
      - EdgeCell
      - QuadCell
      - HexaNode
      - QuadNode
      - EdgeNode
      - VertexNode
- its elements.

To define groups on the model in the **Main Menu** select **Groups -> Add Group**.

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/gui_add_group.png)

**Add group**

## Remove group

To remove a group from the model, in the **Groups Tab’s Tree View** select the group you want to remove then click on **Groups -> Remove Group** in the main menu.

TUI command: [Define groups on the model of blocks](tui_groups.md#tuigroups)
