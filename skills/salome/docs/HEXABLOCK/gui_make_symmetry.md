# Make elements by symmetry

To make elements by symmetry elements in the **Main Menu** select
**Model -> Operation -> Make symmetry**.

## Make elements by point symmetry

**Arguments:**

- elements,
- vertex.

The dialogue box to make elements by point symmetry is:

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/gui_make_point_symmetry.png)

**Make Elements by point symmetry**

### Example

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/sph_grid_for_make_sym_examle.png)

**Spherical grid**

A point symmetry on the *Spherical grid* gives the following result:

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/make_point_symmetry.png)

**Point symmetry on *Spherical grid***
