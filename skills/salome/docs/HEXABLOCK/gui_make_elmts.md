# Make elements by transforming elements

To make elements by transforming elements in the **Main Menu** select
**Model -> Operation -> Make transformation**.

## Make elements by translation

**Arguments:**

- elements to translate,
- vector.

The dialogue box to make elements by translation is:

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/gui_make_transfo_translation.png)

**Make Elements by Translation**

Example:

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/transfo0.png)

**Before Transforming**

![figure](https://docs.salome-platform.org/latest/gui/HEXABLOCK/_images/transfo_translation.png)

**Make Translation**
